# Baneh360

Baneh360 is a local super-app for Baneh, designed for both residents and visitors.

## Product pillars

- **Explore** — stores, restaurants, hotels, attractions, parking and essential places.
- **Shop** — discover products, compare prices and find verified sellers.
- **Deals** — local discounts, coupons and limited-time offers.
- **Travel** — accommodation, food, routes and visitor essentials.
- **Services** — trusted local services for residents and travelers.

## Monorepo

- `apps/mobile` — Expo / React Native app for Android, iOS and web/PWA.
- `apps/admin` — Next.js admin and merchant dashboard.
- `packages/shared` — shared domain types.
- `supabase` — PostgreSQL schema and migrations.
- `docs` — product and architecture notes.

## Getting started

```bash
corepack enable
pnpm install
pnpm dev:mobile
# or
pnpm dev:admin
```
